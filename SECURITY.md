# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Mojo Party Bot, please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting feature for this repository (Security tab -> Report a vulnerability), or contact the maintainer directly.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs or screenshots (with tokens, passwords, and other secrets redacted)

## Scope

This covers the Mojo Party Bot source code itself. It does not cover:

- Discord's own platform or API
- Third-party dependencies (report those upstream)

## Supported versions

Only the latest version on the `main` branch receives security fixes.
